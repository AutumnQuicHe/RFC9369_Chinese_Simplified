在《[QUIC TLS](/RFC9001_Chinese_Simplified/)》中用于推导包保护密钥（详见[第5.1章]()）、头部保护密钥（详见[第5.4章]()）、重试完整性标签密钥（详见[第5.8章]()）以及密钥升级（详见[第6.1章]()）的标签，分别从“quic key”改为“quicv2 key”、“quic iv”改为“quicv2 iv”、“quic hp”改为“quicv2 hp”以及“quic ku”改为“quicv2 ku”，从而满足该文档[第9.6章](/RFC9001_Chinese_Simplified/#9.6_Key_Diversity)对新版本的要求。
