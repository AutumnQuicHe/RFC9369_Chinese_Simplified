用于重试完整性标签（Retry Integrity Tag）的密钥和随机数（详见《[QUIC TLS](/RFC9001_Chinese_Simplified/)》[第5.8章](/RFC9001_Chinese_Simplified/#5.8_Retry_Packet_Integrity)）改为：

```
secret = 0xc4dd2484d681aefa4ff4d69c2c20299984a765a5d3c31982f38fc74162155e9f
key = 0x8fb4b01b56ac48e260fbcbcead7ccc92
nonce = 0xd86969bc2d7c6d9990efb04a
```

其中`secret`（密码）就是“QUICv2 retry secret”的`sha256sum`值。
密钥和随机数分别通过标签“quicv2 key”及“quicv2 iv”从这个密码派生而来。
